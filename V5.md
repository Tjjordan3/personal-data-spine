# DonePath — v5.0.0

Frozen scope for the M0–M6 DonePath release. A full static copy lives at `../personal-data-spine-v5/`.

Active development continues in `../personal-data-spine/` on the `v6` branch (see [V6.md](V6.md)).

To tag in git after setting `user.name` / `user.email`:

```bash
git tag v5.0.0
git checkout -b v6
```

## Shipped in v5

- [x] **M0 — Backup & data** — Settings panel: DB path, SQLite + JSON export, destructive restore, last backup time
- [x] **M1 — Command palette** — `Ctrl+K` / `Cmd+K`, navigation, create, focus timer, item search
- [x] **M2 — Focus actions** — Start / Done / Snooze / Reschedule / Log outcome; Start next; snooze until date
- [x] **M3 — Meetings leverage** — Linked task rollup, notes-only save, decisions parser, project on tasks, shortcuts, Start focus from sidebar
- [x] **M4 — Search & graph** — FTS5 index, link picker, linked-to-selection filter, spring graph layout
- [x] **M5 — Capture templates** — Meeting + note templates; global shortcuts in Settings
- [x] **M6 — Polish** — Empty states, mark visible done, FTS performance
- [x] **Meetings hub** — split view: past meetings list + compose/detail
- [x] **Meeting title** — `metadata.title` on save; title field in compose and edit
- [x] **Meetings linked-task sidebar** — edit linked tasks in right column without losing meeting selection
- [x] **UI transitions** — faster view-enter animations
- [x] **Windows dev fix** — Vite bound to `127.0.0.1` for WebView2

## Optional later (v6+)

- Projects hub parity with Meetings (3-column layout, linked-task sidebar)
- Focus integration from meeting tasks (beyond Start focus button)
- Pomodoro from meeting task rows (timer bar)
- Subscription renewal local notifications

## Out of scope (for now)

- Cloud sync or multi-device
- Mobile client
- OAuth / third-party calendar APIs
