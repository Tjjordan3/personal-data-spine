# Personal Data Spine — v4

Active development in this repository on the `v4` branch.

Builds on the frozen v3 snapshot at `../personal-data-spine-v3/` ([V3.md](V3.md)).

## Shipped in v4

- [x] **Pomodoro timer (Focus)** — task-required focus sessions, `work_block` logging, today minutes + streak in Today/Focus, 25/5 presets, keyboard shortcuts, break mode, resume last task

## Planned for v4

- [ ] **FTS5 search** — SQLite full-text index for content/tags; faster inbox search
- [ ] **Link picker** — search and select items when linking (replace paste-ID flow)
- [ ] **Graph improvements** — optional force-directed layout; filter inbox to “linked to selection”
- [ ] **Title field** — optional `metadata.title` (or column) distinct from body `content` for notes, tasks, meetings
- [ ] **Project ↔ task wiring** — assign tasks to projects from edit form; roll up due items on project cards
- [ ] **Subscription reminders** — optional local notifications before renewal (Tauri plugin)
- [ ] **Export / backup** — one-click JSON or SQLite export from Settings

## Out of scope (for now)

- Cloud sync or multi-device
- Mobile client
- OAuth / third-party calendar APIs
