# Personal Data Spine — v4.0.0

Frozen scope for the Pomodoro and focus-timer release. A full static copy lives at `../personal-data-spine-v4/`.

Active development continues in `../personal-data-spine/` on the `v5` branch (see [V5.md](V5.md)).

To tag in git after setting `user.name` / `user.email`:

```bash
git tag v4.0.0
git checkout -b v5
```

## Shipped in v4

- [x] **Pomodoro timer (Focus)** — task-required focus sessions, `work_block` logging, today minutes + streak in Today/Focus, 25/5 presets, keyboard shortcuts, break mode, resume last task
- [x] **Pomodoro completion chimes** — optional audio feedback when a work or break block ends
- [x] **Light mode text contrast** — `pds-*` tokens tuned for readable body and muted text in light theme
- [x] **Start focus from task** — start a Pomodoro directly from task edit / selection flows
- [x] All v3 features (see [V3.md](V3.md))

## Deferred (see v5 or later)

- [ ] **FTS5 search** — SQLite full-text index for content/tags; faster inbox search
- [ ] **Link picker** — search and select items when linking (replace paste-ID flow)
- [ ] **Graph improvements** — optional force-directed layout; filter inbox to “linked to selection”
- [ ] **Title field (global)** — optional `metadata.title` for notes and tasks (meetings: v5)
- [ ] **Project ↔ task wiring** — assign tasks to projects from edit form; roll up due items on project cards
- [ ] **Subscription reminders** — optional local notifications before renewal (Tauri plugin)
- [ ] **Export / backup** — one-click JSON or SQLite export from Settings

## Out of scope (for now)

- Cloud sync or multi-device
- Mobile client
- OAuth / third-party calendar APIs
