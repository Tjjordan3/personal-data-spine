# Personal Data Spine — v3.0.0

Frozen scope for the focus-and-organization release. A full static copy lives at `../personal-data-spine-v3/`.

Active development continues in `../personal-data-spine/` on the `v4` branch (see [V4.md](V4.md)).

To tag in git after setting `user.name` / `user.email`:

```bash
git tag v3.0.0
git checkout -b v4
```

## Shipped in v3

- [x] **Light / dark theme** — class-based Tailwind v4 (`dark` on `<html>`), CSS variables (`pds-*` tokens), persisted in `localStorage` via `pds-settings.theme` (`light` | `dark` | `system`; default `system`)
- [x] **Theme controls** — compact toggle in header; full Light / Dark / System in Settings
- [x] **Focus view (Today)** — primary nav tab with hero summary and urgency-sorted stream
- [x] **Tasks due** — overdue, today, and due within 7 days (reuses `metadata.due_date`)
- [x] **Subscription renewals** — type `subscription` with `metadata.renewal_date`, optional `amount`, `cadence`, `status`, `notes`
- [x] **Subscriptions tab** — browse and add subscriptions (picker + renewal tracking)
- [x] **Active projects** — type `project` with `metadata.status`, priority, area, target date, `notes`
- [x] **Projects tab** — create and manage projects outside the inbox stream
- [x] **New types in inbox** — facets, quick-create, and edit forms for `subscription` and `project`
- [x] **`show_capture` command** — Focus empty-state can open the global capture window
- [x] All v2 features (see [V2.md](V2.md))

## Item types

| Type | Key metadata |
|------|----------------|
| `note` | — |
| `meeting` | `parsed_at`, `task_count` |
| `task` | `due_date`, `owner`, `meeting_id`, `project_id?` |
| `subscription` | `renewal_date`, `amount?`, `cadence?`, `status?`, `notes?` |
| `project` | `status`, `notes?`, `priority?`, `area?`, `target_date?` |

No Rust SQL migrations — schema remains `TEXT` type column + JSON metadata via `ensureCoreSchema`.
