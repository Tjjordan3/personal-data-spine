- [x] `item_links` join table + backfill from meeting tasks

- [x] Search with facets: date range, due-soon, type/tag/status
- [x] “Why this appears” match reasons on each card
- [x] Capture: editable tags, stay-open save loop, Ctrl+Z undo
- [x] Quick create from inbox type filter (note / meeting / task)
- [x] Edit items: content, tags, task owner/due/meeting link
- [x] Runtime schema in TypeScript (no Rust migration checksum issues)
- [x] All v1 features: capture, meeting parser, mark/archive/delete
