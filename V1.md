# Personal Data Spine — v1.0.0

Frozen scope for the initial release. A full copy lives at `../personal-data-spine-v1/`.

## Included in v1

- Single SQLite `items` table (note, meeting, task)
- Quick capture overlay (`Alt+Shift+Space`), Enter to save, Esc dismiss
- Keyword + hashtag auto-tagging
- Meeting mode: heuristic parse, optional LLM refine, preview table
- One-way task → meeting link via `metadata.meeting_id`
- Inbox: text search, type/tag/status filters
- Mark done / archive / restore / delete

## Not in v1 (see v2)

- Bidirectional links and join table
- Related items / graph view
- Date-range and due-soon facets
- Search match explanations
- Capture: editable tags, save loop, undo
