# DonePath — v6.0.0

**Frozen** scope for the v6 DonePath release. A full static copy lives at `../personal-data-spine-v6/`.

Active development continues on the **`v7`** branch only (see [V7.md](V7.md)). The v6 milestone is frozen at git tag **`v6.0.0`** and snapshot `../personal-data-spine-v6/`.

Product name: **DonePath** (repo folder remains `personal-data-spine`).

Builds on the frozen v5 snapshot at `../personal-data-spine-v5/` ([V5.md](V5.md)).

To tag in git after setting `user.name` / `user.email` (milestone name; app version in `package.json` may differ):

```bash
git tag v6.0.0
git checkout -b v7
```

## Shipped in v6

### Subscriptions hub (Meetings / Projects parity)

- [x] **3-column layout** — left subscription list (search + status filters), center detail (renewal, cost, notes, Edit), right related items via `RelatedPanel`
- [x] **Add subscription** — catalog picker in center column when nothing selected
- [x] **Renewal reminders** — local Windows toasts for active subscriptions renewing within 7 days; Settings toggle; deduped per subscription + renewal date per day

### Projects tab (Meetings parity)

- [x] **3-column layout** — left project list, center project detail (view + Edit), right linked tasks
- [x] **Linked-task sidebar edit** — clicking a linked task opens `ItemEditForm` in the right column; project stays selected in center
- [x] **Richer linked-task cards** — status badge, due date, overdue, Done/Restore, Start focus
- [x] **Add task to project** — quick action when a project is selected (`project_id` preset)
- [x] **New project** — button in left column header (like Meetings)

### Power user / depth

- [x] **ICS export** — active tasks with due dates → `.ics` (Settings, command palette)
- [x] **Graph scope** — inbox graph: full graph vs selection neighborhood
- [x] **Duplicate item** — copy with new id; optional one-hop links
- [x] **Meeting templates** — user templates in localStorage; duplicate last meeting
- [x] **Recurring tasks/subscriptions** — weekly/monthly/yearly metadata + Focus stream
- [x] **Markdown folder import** — `.md` → notes with `#imported` and path dedupe

### Also shipped in v6 (beyond Projects hub)

- [x] **Leverage in daily flow** — shared snooze/reschedule on hub task rows; command palette (go to project, new meeting from template, export backup); post-meeting-save quick actions
- [x] **Typography & shell** — IBM Plex Sans, type scale, nav icons, milestone branding
- [x] **Graph readability** — responsive graph, icon nodes, legend, focus/hover labels
- [x] **Windows releases** — GitHub Actions + [RELEASING.md](RELEASING.md); installers on Releases
- [x] **Security docs** — [SECURITY.md](SECURITY.md); LLM privacy blurb in Settings

### Optional later (shipped in v6)

- [x] **Related-items panel for projects** — right-column section below linked tasks (like inbox Related)
- [x] **Project compose flow** — center column goals template when nothing selected (Meetings parity)
- [x] **Subscription / inbox cross-links** — link picker on project; navigate to Subscriptions or Inbox on click

## Out of scope (for now)

- Cloud sync or multi-device
- Mobile client
- OAuth / third-party calendar APIs
